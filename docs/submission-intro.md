# 作品简介（≤200 字）

一款“说话就能办业务”的银行 AI 智能体 PWA：短信验证注册、找回密码、设备会话管理与独立数据空间；大模型解析 + Agent DAG 安全执行转账、账单、理财、卡片、订阅与生日联动，内置风险测评适当性校验与交易争议工单。默认合成数据演示，另备签名银行核心与短信/人脸核验接入层；绿色自动、黄色确认、红色强验证，配合一次性授权、注入防御、数字守卫、哈希链审计与受限沙箱，回执由工具结果渲染。

## 备选短句（答辩/海报用）

- 能办事，也敢让它办事。
- 模型只负责理解，安全交给执行层。
- 每一笔操作，都有一张可校验的“通行证”和一条可追溯的审计链。
- 权限、审计和回退做进 Agent 的执行骨架，聊天框只是入口。
- 一个能登录、能安装、能分享，也敢让评委看底层链路的银行 Agent 产品原型。
